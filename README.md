# 🎓 Student Management System

A Python-based Student Management System built using Python and JSON. This project allows users to manage student records through a simple menu-driven interface.

---

## ✨ Features

- ➕ Add Student
- 📋 Display Students
- 🔍 Search Student by ID
- ✏️ Update Student Details
- ❌ Delete Student
- 📊 Student Statistics
- 🔄 Sort Students
- 💾 Automatic JSON Storage
- ✅ Input Validation
- 🚫 Duplicate ID Detection
